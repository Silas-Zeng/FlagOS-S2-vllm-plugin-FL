# native SiLU 相邻两列访存组件

现有072151轨迹中，M2048每步34个 native SiLU尾处理合计约7.795 ms。只比较相邻两列 int2/float2 读取及 packed BF16写回，原量化、整数GEMM、两次BF16舍入、expf和FP32结合顺序保持。PR30是跨距多项循环扫参；本项不扫描线程数或items、不融合GEMM，也不改变生产SO。

入口 `python3 entry.py` 由主线程统一启动。原轻owner设备锁/9031/DB/420秒及清理原样复用；新run写入framework独立目录。先按原构建flags编译私有命名空间库：baseline内核与CPP函数原字节；candidate复制同函数，仅epilogue callee不同。编译日志、生成库和SHA均保留，生产14f不加载/替换。

固定M2048/N12288/K2048。隔离尾处理要求完整逐位、guard，独立CPU参考复用PR30容差；完整gate五pattern、变指针与稳定指针换全部输入Graph仍完整逐位。两臂使用同随机输入；各自Graph包含完整尾处理或原quant→GEMM→尾处理及同等分配。性能结合完整gate与隔离机制判断；有可信小正向且无明确回退即可由主线程安排模型实测，不设四项计时都必须正向的硬门。组件不授予模型准确率或官方收益资格。

候选比原核每CTA输出256→512列，可能减少地址/访存指令与CTA调度，也可能增加寄存器压力；不预估净收益。不修改采样或精度容差。出现编译/数值/边界异常立即停止，明确性能负结果则收口，小波动保留原始值由主线程判断。
