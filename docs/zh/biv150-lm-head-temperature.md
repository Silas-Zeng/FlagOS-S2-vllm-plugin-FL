# BI-V150 LM-head 温度融合

在 MiniCPM5-2B 的 32／64 行 LM-head 路径中，把原 BF16 输出舍入后的 FP32 转换和温度除法合入 GEMM epilogue，减少 logits 的中间搬运。原采样参数、统计、top-p、随机数消费及 BF16 舍入保留。其它形状、硬件、不支持的 processor、grammar 或元数据变化走原路径；不支持条件下不会重复除温度。

`VLLM_FL_BIV150_HEAD_TEMPERATURE` 默认开启，设为 `0` 可隔离。实际资格依赖精确的原模型、SDK、权重和采样实现；已有编译缓存身份纳入开关及源码。没有新增常驻权重或 GPU workspace。
