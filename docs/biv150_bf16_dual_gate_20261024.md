# Dual BF16 gate/up accumulator probe — unvalidated

Base: team main 3283672, freshly fetched on 2026-10-24. Operator-only diagnostic,
not installed in serving. No GPU results for this implementation yet.

The previous interleaved paired-column implementation failed to beat actual
FlagGems mm plus one fused activation even after correcting its independent CPU
FP64 reference. This experiment changes the compute structure: two separate
BF16 dot products share the activation tile, avoiding the interleaved output
column arrangement. Both projection outputs are rounded to BF16 before FP32
sigmoid/multiplication, as in the current service.

Two identical-value weight layouts are compared: original [2N,K] and transposed
contiguous [K,2N]. The comparator measures FlagGems mm plus fused activation on
both layouts. Speedup is reported against both the original service layout and
the faster comparator layout, so layout-only gains are distinguishable from
fusion. Packing is setup and excluded from kernel timing, and both copies are
kept only for diagnosis; no memory/capacity benefit is claimed. A serving change
would need a correct single-copy weight lifecycle and capacity measurement.

M=1/8/16/32/40/64/2048, 10 tile configurations and two layouts are covered.
Comparators and candidates use independently sampled CPU FP64 references; all
FP64 conversions happen after copying to CPU because GPU double conversion was
observed to return zeros on this stack. Tolerances remain 0.005 absolute/relative.
Selected M8/M32 configurations test changed-input Graph replay with zero, normal
and scaled inputs. Three alternating timing rounds include actual activation
and complete kernel calls. Compilation, correctness and timing failures are
recorded separately from passing records.

The owned queue waits on the predecessor's PID AND /proc start_ticks, handles
zombies/PID reuse, then independently refuses occupied GPU/service port. It
cannot stop a service. It must not run while residual model acceptance uses the
GPU. New source passes Ruff, Python compilation and whitespace checks only.
